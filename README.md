# ✈️ Airline Analytics Dashboard | Tableau

## 📌 Project Overview

An interactive Tableau dashboard designed to analyze airline performance, passenger trends, ratings, and flight status.

## 📊 Key Metrics

* Total Passengers: **993**
* Total Flights: **541**
* Total Airlines: **6**
* Average Rating: **3.005**

## 🔍 Dashboard Insights

* Passenger Count by Airline
* Average Rating by Airline
* Flight Status by Airline
* Passenger Distribution by Age
* Flight Status Distribution
* Average Rating by Flight Status

## 🛠️ Tools & Technologies

* Tableau
* Data Analysis
* Data Visualization
* CSV Dataset

## 🎯 Objective

To transform airline data into meaningful visual insights and understand passenger trends, airline performance, customer ratings, and flight status distribution.
